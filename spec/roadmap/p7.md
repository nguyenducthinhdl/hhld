# P7 — Crawl and warehouse

- **Status:** done
- **Goal:** Minimal crawl stubs + local warehouse (SQLite/Parquet) to persist ticks for backtest.
- **Done when:** crawled sample data lands in warehouse and can feed P6.
- **Skip:** full historical coverage, multi-cloud storage.

## Delivered

- `src/warehouse/sqlite.go`: file-backed `Store` (books + ticks)
- `src/sim/input.go`: `InputFromStore` loads warehouse → `sim.Input` for replay
- `src/crawl/`: `Crawler` interface; `SampleFile` (NDJSON) and `FakeDual` (scripted, no network)
- `data/samples/btcusd_books.ndjson`: bundled dual-venue book history with one arb gap
- `cmd/hhld-crawl`: load sample or fake data into SQLite (`-sample` / `-fake` / `-db`)
- Test: crawl sample → warehouse → `sim.Replay.Run` → positive PnL
- `go test ./...` passes

## Usage

```bash
go run ./cmd/hhld-crawl -sample data/samples/btcusd_books.ndjson -db ./hhld.db
# warehouse.LoadInput(...) → sim.NewReplay().Run(...) in Go, or extend CLI later
```

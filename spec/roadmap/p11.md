# P11 — Local + venue write adapters (create order)

- **Status:** pending
- **Depends on:** [P10](p10.md) (order forensics / unknown-ack tracing)
- **Goal:** Place an order with **kind** (`perp` | `spot`), **symbol**, **side**, and **volume** (base size) through the same `Exchange.PlaceOrder` on three envs: **local** (in-process fake matcher, no capital) → venue **staging/testnet** → **production**. Local trading (one-leg CLI + two-leg Runner) must work before any signed venue write.
- **Done when:**
  - `cmd/hhld-place -env local` and `cmd/hhld -trade-local` submit `{kind, symbol, side, size}` through fake `PlaceOrder` / `CancelOrder` / `GetOrder`; ack + TraceID land in admin audit.
  - Both HL and GRVT adapters implement signed place/cancel/reconcile for `perp` and `spot`.
  - Staging/testnet smoke is documented and repeatable; production smoke is opt-in and cannot run by accident.
  - Secrets never live in JSON config, logs, or git; env hosts cannot be mixed with the wrong keys; **local never loads live keys**.
  - Trading **ledger** SQLite (`hhld-ledger.db`) stores orders + fills; realized PnL rebuilds from fills after restart (see [ledger.md](../ledger.md)). The warehouse `books`/`ticks` schema is **not** used for PnL.
- **Skip:** automatic **venue** live arb (Runner on staging/prod); Polymarket; maker-taker strategy; withdrawals / transfers / deposits; admin HTTP buttons that place staging/prod orders.

See API contracts below. Ledger / realized PnL schema: [ledger.md](../ledger.md). High-level order in [../roadmap.md](../roadmap.md). Venue notes: [hyperliquid.md](../exchange/hyperliquid.md), [grvt.md](../exchange/grvt.md). Doctrine: [networking.md](../networking.md), [concurrency.md](../concurrency.md).

## Why this slice (not full live arb)

Paper already emits two-leg Decisions. Live **write** is a different failure mode (signed auth, unknown acks, unpaired exposure). P11 proves the **same place stack** on local first, then **one order on one venue**, before the Runner is allowed to spend capital.

```text
                    kind, symbol, side, size [, price]
                                    │
                                    ▼
                    Risk size/budget gates (P4; miss-more)
                                    │
                                    ▼
                    Exchange.PlaceOrder  (env picks the adapter)
                         │                │                │
                    -env local      staging/testnet      prod/mainnet
                    fake matcher    signed HL/GRVT       signed HL/GRVT
                         │                │                │
                         └────────────────┴────────────────┘
                                          ▼
                         OrderAck + GetOrder → admin audit (TraceID)
```

Env ladder (do not skip rungs):

```text
local  →  staging / testnet  →  production / mainnet
```

`-paper-live` **must not** grow a “just flip this flag” to staging/prod. Signed venue writes live in `cmd/hhld-place` (and only that binary loads keys). Local trading uses the same CLI flags and `OrderRequest` but the fake adapter — no secrets.

## Order request (HHLD)

Existing `OrderRequest` already carries `Symbol`, `Kind`, `Side`, `Size`, `Price`, `ClientOrderID`, `TraceID`. P11 extends it only as needed for venue writes:

| Field | Required | Meaning |
|-------|----------|---------|
| `Kind` | yes | `perp` or `spot` (prediction out of scope) |
| `Symbol` | yes | HHLD id (e.g. `BTCUSD`); adapter maps to native instrument |
| `Side` | yes | `buy` / `sell` |
| `Size` | yes | **Volume in base** (BTC for BTCUSD), same unit as `trading.max_size` |
| `Price` | if limit | Decimal string. If empty: snapshot TOB (buy = best ask, sell = best bid) and send **IOC** |
| `TIF` | default IOC | `Ioc` (HL) / `IMMEDIATE_OR_CANCEL` (GRVT). GTC/ALO later |
| `ReduceOnly` | default false | Optional; not required for the first smoke |
| `ClientOrderID` | generated | Stable id for reconcile; HL `cloid` = 128-bit hex |

CLI shape (implementation). **Default `-env` is `local`.**

```bash
# Local one-leg (no network, no keys) — first smoke
go run ./cmd/hhld-place \
  -config configs/default.json \
  -venue hyperliquid \
  -env local \
  -kind perp \
  -symbol BTCUSD \
  -side buy \
  -size 0.00003

# Local two-leg trading loop (fake books + fake place, P11 OrderRequest)
go run ./cmd/hhld -trade-local -config configs/default.json
# optional: -trade-local -live-books   # public HL+GRVT books, still fake place

# Staging / testnet (HL signed place; requires HHLD_LIVE_ORDERS=1 + HL_TESTNET_*)
go run ./cmd/hhld-place \
  -config configs/default-staging.json \
  -venue hyperliquid \
  -env testnet \
  -kind perp \
  -symbol BTCUSD \
  -side buy \
  -size 0.00003

# GRVT staging place not in this slice yet
# go run ./cmd/hhld-place \
#   -config configs/default-staging.json \
#   -venue grvt \
#   -env staging \
#   ...
```

Optional `-price` for an explicit limit. Volume is **base size**, not USD notional. Reject if size `> trading.max_size`, notional outside `trading.min_value`/`max_value`, or notional would exceed `venues.<venue>.budget`.

### Kind → native instrument

Config today has one `symbol_name` per venue (perp). Spot is a **different** product — do not reuse the perp id.

| HHLD | Kind | Hyperliquid | GRVT |
|------|------|-------------|------|
| `BTCUSD` | `perp` | coin `BTC` (asset = `meta.universe` index) | `BTC_USDT_Perp` |
| `BTCUSD` | `spot` | spot pair from `spotMeta` (asset = `10000 + index`, e.g. `PURR/USDC` is `10000`) | spot instrument (e.g. `BTC_USDT` — **confirm at implement**) |
| `ETHUSD` / `SOLUSD` / `TRUMPUSD` | `perp` | existing `craw-*.json` maps | existing `*_USDT_Perp` |

Add optional `spot_symbol_name` on `VenueSpec`. `Kind=spot` without a map → error (no silent perp fallback). Same-kind arb stays **perp**; spot place is for venue integration and later hedge legs.

## Environments

Pick **one** env per process. Hosts and credentials are paired; mixing is a hard error. **Local has no hosts and no credentials.**

| `-env` | Writes | Books | Capital | Keys |
|--------|--------|-------|---------|------|
| `local` (default) | `exchange/fake` in-process matcher | fake dual books, or public HL+GRVT reads (`-live-books`) | none | **refused** if present |
| HL `testnet` / GRVT `staging` then `testnet` | signed venue `PlaceOrder` | public market data on that env | faucet / staging | env-specific |
| HL `mainnet` / GRVT `prod` | signed venue `PlaceOrder` | public market data | **real** | env-specific + dual confirm |

### Local trading

Local is the same product as staging/prod: `{kind, symbol, side, size}` → Risk → `PlaceOrder` → ack → `GetOrder` → admin. Only the adapter behind `PlaceOrder` is fake.

| Mode | Command | Market data | Place |
|------|---------|-------------|-------|
| One-leg smoke | `hhld-place -env local` | Optional snapshot from fake book (or `-price`) | Fake fill/rest; `GetOrder` in memory |
| Two-leg loop | `hhld -trade-local` | Fake books (like `-demo-market`) | Fake place on both venue IDs (`hyperliquid`, `grvt`) |
| Two-leg, live tape | `hhld -trade-local -live-books` | Public HL+GRVT books (like `-paper-live`) | Still fake place |

`-trade-local` is the P11 successor of `-paper-live` for **writes**: it uses the extended `OrderRequest` (TIF, cloid, `GetOrder`) so local and venue smokes share one code path. Keep `-paper-live` working until `-trade-local` is the default; do not point `-paper-live` at signed adapters.

Fake matcher duties (extend `src/exchange/fake` as needed):

- Honor `Kind` (`perp` / `spot`), `Side`, `Size`, optional `Price`; default IOC (fill at TOB or reject).
- `GetOrder` by `OrderID` / `ClientOrderID`; `CancelOrder` if resting.
- Simulate timeout / unknown ack (test hook) so reconcile is exercised locally.
- Same `VenueID` strings as live (`hyperliquid`, `grvt`) so audit and Risk budgets match.

Local **must not** open `trades.*` or `/exchange` write hosts. If `-env local` and any live private key / API key is set, **refuse to start** (fail closed) so a mis-sourced `.env` cannot leak into a “local” process.

### Hyperliquid

| Env (`-env`) | REST | WS (books; still public) | Capital |
|--------------|------|--------------------------|---------|
| `testnet` | `https://api.hyperliquid-testnet.xyz` | `wss://api.hyperliquid-testnet.xyz/ws` | faucet / test USDC |
| `mainnet` | `https://api.hyperliquid.xyz` | `wss://api.hyperliquid.xyz/ws` | **real** |

Place: signed `POST {REST}/exchange`. L1 order actions sign with the documented Agent / chain-id **1337** scheme (same for testnet and mainnet). User-signed transfers use a **different** chain id — **out of scope** (do not implement withdraw).

### GRVT

| Env (`-env`) | Auth login | Trade REST | Trade WS | L2 chain id (order sig) |
|--------------|------------|------------|----------|-------------------------|
| `staging` | `https://edge.staging.gravitymarkets.io/auth/api_key/login` | `https://trades.staging.gravitymarkets.io` | `wss://trades.staging.gravitymarkets.io/ws/full` | `327` |
| `testnet` | `https://edge.testnet.grvt.io/auth/api_key/login` | `https://trades.testnet.grvt.io` | `wss://trades.testnet.grvt.io/ws/full` | `326` |
| `prod` | `https://edge.grvt.io/auth/api_key/login` | `https://trades.grvt.io` | `wss://trades.grvt.io/ws/full` | `325` |

Place: API-key login → `Cookie: gravity=…` + `X-Grvt-Account-Id`, then `POST {Trade}/full/v1/create_order` with an EIP-712 **order** signature (cookie auth ≠ order sig). Prefer **full** field names (same as P8 reads).

**Test order:** local (both venues, perp then one spot) → GRVT staging + HL testnet → production/mainnet with the live gate below.

## API contracts (re-check at implement time)

Sources: [HL exchange endpoint](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint), [GRVT trading API](https://api-docs.grvt.io/trading_api/), [GRVT API setup](https://api-docs.grvt.io/api_setup/).

### Local — `PlaceOrder`

No HTTP. `exchange/fake` (venue IDs `hyperliquid` / `grvt`) implements the same `PlaceOrder` / `CancelOrder` / `GetOrder` as the live adapters.

| HHLD | Fake behavior |
|------|----------------|
| `Kind` / `Symbol` / `Side` / `Size` | Accepted; unknown symbol → reject |
| empty `Price` | Fill IOC at last fake TOB (or reject if no book) |
| `TIF` IOC | Fill or cancel remainder immediately |
| Timeout hook | Test-only delay → caller treats as unknown ack |

Do not reuse paper’s implicit “always accepted” ack without `GetOrder` — local must exercise the P11 reconcile path.

### Hyperliquid — `PlaceOrder`

`POST /exchange`, body `{ action, nonce, signature [, vaultAddress] [, expiresAfter] }`.

`action.type = "order"`; one element in `orders[]`:

| Wire | From HHLD |
|------|-----------|
| `a` (asset) | `Kind=perp` → `meta` universe index for mapped coin; `Kind=spot` → `10000 + spotMeta` index |
| `b` (isBuy) | `Side == buy` |
| `p` / `s` | `Price` / `Size` (strings) |
| `r` | `ReduceOnly` (default false) |
| `t` | `{ "limit": { "tif": "Ioc" } }` for this phase |
| `c` | `ClientOrderID` as 128-bit hex `cloid` |

Ack: `status=ok` + `resting.oid` **or** `filled.{totalSz,avgPx,oid}` **or** `error`. Map to `OrderAck.Status` (`accepted` / `filled` / `rejected`) and `OrderID`. Venue error string → typed reject (safe: no position). HTTP/timeout → **unknown ack** ([networking.md](../networking.md)): do **not** retry the same cloid until `GetOrder`.

Reconcile: `POST /info` `{ "type": "orderStatus", "user": <address>, "oid": … }` (or cloid variant — confirm). Cancel: `action.type=cancel` / `cancelByCloid`.

### GRVT — `PlaceOrder`

1. `POST {auth}/auth/api_key/login` `{ "api_key": … }` → `Set-Cookie: gravity=…`, header `X-Grvt-Account-Id`.
2. `POST {trades}/full/v1/create_order` with those headers.

Order body (full names; skip unused TP/SL / RFQ):

| Wire | From HHLD |
|------|-----------|
| `sub_account_id` | env `GRVT_SUB_ACCOUNT_ID` |
| `is_market` | false when `Price` set; true only if we omit price (still send IOC + TOB cap) |
| `time_in_force` | `IMMEDIATE_OR_CANCEL` |
| `post_only` / `reduce_only` | false / `ReduceOnly` |
| `legs[0].instrument` | native from kind+symbol map |
| `legs[0].size` | `Size` |
| `legs[0].limit_price` | `Price` |
| `legs[0].is_buying_asset` | `Side == buy` |
| `signature` | EIP-712 over the order; `chain_id` must match env table above |

Reconcile: `POST full/v1/order` (and/or `open_orders`). Cancel: `full/v1/cancel_order`. Enable **cancel-on-disconnect** for the place process when the API allows it.

`Fill.Fee` from venue reports when present; otherwise leave empty and let admin keep the Risk schedule (same rule as [trading.md](../trading.md)).

### Interface delta

```text
Exchange
  PlaceOrder(ctx, OrderRequest) (OrderAck, error)   # live, not ErrReadOnly
  CancelOrder(ctx, orderID) error
  GetOrder(ctx, query) (OrderAck, error)            # NEW — unknown-ack reconcile
```

Strategy / risk / PnL still **must not** import vendor SDKs. Signing stays inside `src/exchange/hyperliquid` and `src/exchange/grvt` (plus a small `src/secrets` or adapter-local loader).

## Security

P11 is the first code that can spend money. Defaults are **closed**.

### Secrets

| Rule | How |
|------|-----|
| Never in git / JSON configs / fixtures | Keys only from environment or a `0600` file outside the repo. Track `.env.example` with empty values. `.env*` already gitignored |
| Never in logs | Redact private keys, API keys, cookies, signatures. Log venue, env, kind, symbol, side, size, cloid, TraceID only |
| Split by env | Distinct vars or files: `HL_TESTNET_PRIVATE_KEY` vs `HL_MAINNET_PRIVATE_KEY`; `GRVT_STAGING_API_KEY` vs `GRVT_PROD_API_KEY`. Refuse if the chosen `-env` has no matching secret |
| Least privilege | HL: **API/agent wallet**, not the master deposit wallet. GRVT: API key with **trade** permission only (no transfer/withdraw). Order signing key stays on the box |
| No secret on the wire except signatures | Private keys never leave the process; venues see EIP-712 / L1 action signatures only |

Suggested env (names may shift at implement; keep the split):

```text
HHLD_LIVE_ORDERS=0          # must be 1 for staging/prod PlaceOrder; local ignores and stays 0
HHLD_VENUE_ENV=local        # must equal -env; default local
HHLD_KILL=0                 # 1 → refuse new places; best-effort cancel-all (venue envs)

HL_ACCOUNT_ADDRESS=0x…
HL_TESTNET_PRIVATE_KEY=     # hex; agent wallet
HL_MAINNET_PRIVATE_KEY=

GRVT_STAGING_API_KEY=
GRVT_STAGING_SUB_ACCOUNT_ID=
GRVT_STAGING_SIGNING_KEY=
GRVT_TESTNET_API_KEY=
GRVT_TESTNET_SUB_ACCOUNT_ID=
GRVT_TESTNET_SIGNING_KEY=
GRVT_PROD_API_KEY=
GRVT_PROD_SUB_ACCOUNT_ID=
GRVT_PROD_SIGNING_KEY=
```

### Live gates (cannot skip)

1. **Default deny (venue writes).** HL/GRVT adapters stay `ErrReadOnly` unless constructed with an explicit live `Auth` + `HHLD_LIVE_ORDERS=1`. Local fake place does not use that flag.
2. **Env pin.** Adapter REST/WS hosts are a function of `-env` only (no free-form URL flags). If `HHLD_VENUE_ENV` ≠ `-env`, refuse. `local` has an empty host table.
3. **Local isolation.** `-env local` / `-trade-local` refuse to start if any venue private key, API key, or cookie is in the environment. They never dial trade hosts.
4. **Production dual confirm.** `-env mainnet` or `-env prod` also requires `-i-understand-this-is-production`. Staging/testnet does not. Local does not.
5. **Size / budget.** Same Risk caps as paper (`max_size`, venue `budget`). Production smoke uses a **stricter** cap (document a tiny default, e.g. notional ≤ configured budget and ≤ a hard code ceiling). Local still enforces `max_size` / budget so the gates are proven before staging.
6. **Kill switch.** `HHLD_KILL=1` (or a local `kill` file) refuses `PlaceOrder` and, on venue envs, attempts cancel-all / GRVT cancel-on-disconnect.
7. **No live place on admin HTTP.** `/trading/*` stays read-only for staging/prod. Local loop may show the same PnL/orders pages; still no HTTP place button.
8. **One-leg CLI on venues.** `hhld-place` against staging/prod sends **one** venue order (no two-leg arb). Local two-leg is only `-trade-local`. Flatten leftover **venue** inventory by hand or a documented reduce-only follow-up.
9. **Unknown ack.** Timeout → `GetOrder` by cloid; never double-send. Persist the attempt under TraceID even when the ack is unknown (P10 forensics). Fake adapter must be able to inject this case.
10. **Paper process isolation.** `cmd/hhld -paper-live` and `-trade-local` must not load live signing keys.

### What we are not doing in P11

- Storing keys in `configs/*.json`
- Logging request signatures or cookies
- Withdraw / transfer endpoints (wrong key scope on purpose)
- Kubernetes secrets / vault products (solo box: env files + `0600` is enough)

## Trading ledger (PnL)

Verified: `warehouse` `books`/`ticks` **cannot** realize PnL. P5 `admin`/`pnl` memory **can**, until restart. P11 writes a separate SQLite ledger (`hhld-ledger.db`) whose **fills** table is the source of truth.

| View | Key | What it answers |
|------|-----|-----------------|
| `fills` (append-only) | `(env, venue, fill_id)` unique | Actual px/size/fee; partials; no double-count |
| `positions_strategy` | `(env, symbol, kind, hedge_id)` | Arb realized: buy one venue / sell the other **does** flatten |
| `positions_venue` | `(env, venue, symbol, kind)` | Unpaired inventory and mark-to-market |
| `pnl_events` | per fill | Audit: `SUM(realized)` must equal `positions_*.realized` |

Amounts are decimal **TEXT**. `env` isolates local vs staging vs prod. Full DDL, formula, and check queries: [ledger.md](../ledger.md).

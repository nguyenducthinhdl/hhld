| Venue | Stream | Auth | HHLD event |
|-------|--------|------|------------|

## Contract sufficiency (HHLD vs HL/GRVT)

**Verdict for P9:** market-data contract is **sufficient**. Trading methods exist but are only exercised via `fake`; live order mapping is **not** required for P9.

### Market data — sufficient

| HHLD | Hyperliquid | GRVT |
|------|--------------|------|
| `SubscribeBook` / `Book` | `l2Book` → `WsBook` (`levels[bids,asks]`, `px`/`sz`, `time`) | `v1.book.s` / `v1.book.d` |
| `SnapshotBook` | REST `POST /info` type `l2Book` | REST `POST full/v1/book` |
| `SubscribeTicks` / `Tick` | WS `trades` | WS `v1.trade` |
| Level `Price`/`Size` strings | Matches `px`/`sz` | Matches `price`/`size` |
| Auth | Public | Public market-data WS |

OK to ignore for arb paper: HL level `n`, GRVT `num_orders`, BBO-only, candles, private user streams.

### Trading — interface present; live mapping incomplete

HHLD has `PlaceOrder` / `CancelOrder` + `OrderRequest` / `OrderAck` / `Fill` — enough for **paper** (`fake` + `RecordPaperDecision`).

Against live HL [exchange endpoint](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint):

| Venue needs | On HHLD `OrderRequest` today? |
|-------------|-------------------------------|
| Asset / isBuy / price / size | Partial — Symbol/Side/Price/Size; adapter maps Symbol→asset |
| TIF (`Gtc`/`Ioc`/`Alo`) | **Missing** (live adapter would hard-code, e.g. IOC) |
| `reduceOnly`, trigger/TP-SL, grouping, builder | **Missing** |
| `cloid` 128-bit hex | `ClientOrderID` exists; format not constrained to HL cloid |
| Signed nonce / wallet / vault | Outside interface (auth layer) |
| Ack: resting vs filled `{totalSz,avgPx}` vs error | Thin `Status` + `OrderID` only |
| Cancel by oid or cloid | `CancelOrder(orderID)` only |
| Query order / fills (reconcile) | **Not on interface** — later per [networking.md](../networking.md) |

GRVT live trading needs session cookie + account id and richer order DTOs; market-data path does not.

`Fill` is not produced by `Exchange` today — paper synthesizes fills in `admin.RecordPaperDecision` from leg price/size + Risk fee schedule.

### Phase implication

- **P9:** do not expand `Exchange` for TIF/reconcile/auth; wire public books + fake place.
- **Live capital (after P10 / explicit gate):** extend `OrderRequest` (at least TIF / reduceOnly), add reconcile helpers (`GetOrder` / fill subscribe), implement signed HL/GRVT place adapters.

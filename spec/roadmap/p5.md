# P5 — PnL and admin audit

- **Status:** done
- **Goal:** Persist paper orders and PnL; basic audit via logs or simple store.
- **Done when:** every paper trade is reconstructable (order store + PnL).
- **Skip:** polished UI, visualization charts.

## Delivered

- `src/pnl/memory.go`: in-memory `Tracker` with fill history, inventory realized PnL, `Snapshot` / `SnapshotByHedge`
- **Not** a durable DB: warehouse SQLite is books/ticks only. Durable fills + realized PnL schema is [ledger.md](../ledger.md) (P11).
- `src/admin/memory.go`: in-memory `Auditor` (order store + PnL via tracker)
- `admin.RecordPaperDecision`: maps `PlaceDecision` results → order records + fills with per-venue `FeeSchedule` (failed legs status `error`, no fill)
- `risk.VenueFee` / `FeeSchedule`: exchange-dependent rate, fixed, and commission costs shared by `Gate.Evaluate` and paper fills
- `admin.Handler`: `GET /trading/pnl`, `GET /trading/orders` (HTML + `?format=json`); `cmd/hhld` serves them (`-demo` seeds sample arb)
- Tests: arb PnL after fees, hedge snapshot, list by trace, full paper reconstruct, partial-leg audit on timeout, HTTP handlers
- `go test ./...` passes

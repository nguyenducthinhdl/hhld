# P8 — Hyperliquid + GRVT read adapters

- **Status:** done
- **Goal:** Live/read quote and tick adapters behind `Exchange` for Hyperliquid and GRVT. Verify and lock API contracts first; map both venues into the same internal book/tick types.
- **Done when:** contracts implemented (or amended); both adapters satisfy `Exchange` for configured symbols; strategy/risk/PnL do not import vendor SDKs.
- **Skip:** real order placement.

See API contract tables and normalization duties in [../roadmap.md](../roadmap.md#p8--hyperliquid--grvt-read-adapters).

## Delivered

- `config.SymbolMap` + `Config.NativeSymbol`: HHLD `BTCUSD` → HL `BTC`, GRVT `BTC_USDT_Perp` ([configs/default.json](../../configs/default.json))
- `src/exchange/hyperliquid`: read-only adapter
  - REST `POST /info` `{type:l2Book}` → `SnapshotBook`
  - WS `l2Book` / `trades` → `SubscribeBook` / `SubscribeTicks` (reconnect + fresh snapshot)
  - `PlaceOrder` / `CancelOrder` → `exchange.ErrReadOnly`
- `src/exchange/grvt`: read-only adapter (full field names)
  - REST `POST full/v1/book` → `SnapshotBook`
  - WS `v1.book.s` / `v1.trade` → subscribe streams; event times as unix ns
  - Orders → `ErrReadOnly`
- Shared: `exchange.DialWS`, `AdapterEndpoints`, `ErrReadOnly`
- Unit tests with `httptest` + fake WS (no live network required)
- Strategy / risk / PnL still do not import vendor SDKs
- `go test ./...` passes

## Usage

```go
cfg := config.Default()
hlCoin, _ := cfg.NativeSymbol("hyperliquid", "BTCUSD")
grInst, _ := cfg.NativeSymbol("grvt", "BTCUSD")

hl := hyperliquid.New(hyperliquid.Config{
  Symbols: map[exchange.Symbol]string{"BTCUSD": hlCoin},
})
gr := grvt.New(grvt.Config{
  Symbols: map[exchange.Symbol]string{"BTCUSD": grInst},
})

book, err := hl.SnapshotBook(ctx, "BTCUSD")
```

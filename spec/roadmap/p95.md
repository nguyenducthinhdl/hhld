# P9.5 — Market visualization

- **Status:** done
- **Goal:** Dashboard for dual order books, gap, trade signal, and the config knobs that drive signals.
- **Done when:** `GET /trading/market` shows venue A/B depth, gap, last Decision/miss, and read-only config (fees, size, max volume, min_gap, interval, budgets) in demo mode.
- **Skip:** editing config from UI, TradingView, live capital buttons, separate frontend app.

## Delivered

- [`src/viz`](../../src/viz/): `Snapshot`, `ConfigView`, gap compute, `SignalLog`, `TickRing`.
- [`src/admin`](../../src/admin/): `GET /trading/market` HTML (poll 300ms) + JSON; Runner `SignalNotifier` hook for Decision/miss.
- [`cmd/hhld`](../../cmd/hhld/): `-demo-market` (fake), `-paper-live` / `-live-market` (real HL+GRVT books/ticks, paper place), `-demo` (seeded PnL/orders).
- Dashboard shows native instrument, best bid/ask **price × size**, mid, and depth Price/Size columns.

```bash
go run ./cmd/hhld -demo-market   # fake books
go run ./cmd/hhld -paper-live    # real exchange prices + sizes (alias: -live-market)
# → http://127.0.0.1:8080/trading/market
```
